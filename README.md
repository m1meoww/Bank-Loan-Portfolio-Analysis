# Bank Loan Analysis using Power BI

A comprehensive **Bank Loan Analysis** project built using **Microsoft Power BI** to analyze loan applications, funding, repayments, borrower profiles, loan performance, and risk metrics through interactive dashboards.

## 📊 Project Overview

This project analyzes bank loan data to generate actionable insights and support data-driven lending decisions.

The Power BI report consists of **three interactive dashboards**:

1. **Summary Dashboard**
2. **Overview Dashboard**
3. **Details Dashboard**

---

## 🏦 Dashboard 1: Summary

The Summary Dashboard provides a high-level view of the overall loan portfolio and key performance indicators.

### Key Performance Indicators (KPIs)

| KPI                         | Description                                                                 |
| --------------------------- | --------------------------------------------------------------------------- |
| **Total Loan Applications** | Total number of loan applications received, including MTD and MoM changes   |
| **Total Funded Amount**     | Total amount of funds disbursed as loans, including MTD and MoM changes     |
| **Total Amount Received**   | Total amount received from borrowers through loan repayments                |
| **Average Interest Rate**   | Average interest rate across all loans, including MTD and MoM variations    |
| **Average DTI**             | Average Debt-to-Income ratio of borrowers, including MTD and MoM variations |

### Loan Status Grid

The Loan Status Grid provides a detailed comparison of lending performance across different loan statuses.

It includes:

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* MTD Funded Amount
* MTD Amount Received
* Average Interest Rate
* Average DTI

---

## 📈 Dashboard 2: Overview

The Overview Dashboard provides deeper insights into lending trends and borrower characteristics.

### Visualizations

#### 1. Monthly Trends by Issue Date

**Line Chart**

Shows monthly loan activity to identify:

* Seasonal patterns
* Growth trends
* Changes in lending volume over time

#### 2. Regional Analysis by State

**Filled Map**

Analyzes loan activity across different states to identify:

* High-performing regions
* Regional lending patterns
* Geographic disparities

#### 3. Loan Term Analysis

**Donut Chart**

Shows the distribution of loans across different loan terms.

#### 4. Employee Length Analysis

**Bar Chart**

Analyzes lending metrics based on borrowers' employment length to understand how employment stability relates to loan activity.

#### 5. Loan Purpose Breakdown

**Bar Chart**

Provides a breakdown of loan applications and lending metrics based on loan purpose.

#### 6. Home Ownership Analysis

**Treemap**

Visualizes loan activity based on home ownership categories and helps understand their contribution to the overall loan portfolio.

---

## 🔍 Dashboard 3: Details

The Details Dashboard provides a detailed view of individual loan records and important borrower and loan attributes.

### Objective

The dashboard enables users to efficiently access and analyze critical information related to:

* Loan portfolios
* Borrower profiles
* Loan characteristics
* Risk assessment
* Payment behavior
* Loan performance

### Dataset

The dataset contains important fields including:

* Loan ID
* Address State
* Purpose
* Grade
* Sub Grade
* Annual Income
* Loan Status
* Last Payment Date
* Verification Status
* Debt-to-Income Ratio (DTI)
* Interest Rate

These fields allow analysis of borrower demographics, employment stability, loan characteristics, credit risk, and repayment behavior.
